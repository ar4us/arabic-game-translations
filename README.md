# Arabic Game Translations — تعريب الألعاب

مستودع بيانات وملفات تعريب الألعاب العربية لتطبيق **تعريبHub** من تطوير **ArgusOs**.

## الألعاب المدعومة حالياً
- **Silent Hill: Townfall (سايلنت هيل: تاون فول)** - تعريب كامل من طرف ArgusOs.

## هيكل المستودع
- `manifest.json`: الفهرس الرئيسي لمعلومات وأدلة الألعاب المدعومة والتحقق من صحة الملفات.
- `covers/`: صور وأغلفة الألعاب.
- `Releases`: يتم رفع ملفات التثبيت وحزم التعريب المضغوطة ضمن إصدارات GitHub Releases لكل لعبة.
